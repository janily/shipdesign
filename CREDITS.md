## Tutorial naming notes

The AI LABS tutorial that inspired ShipDesign uses informal labels for several design-skill sources. The verified repository mappings used by ShipDesign are the seven sources in the table above.

For the tutorial's **Perception Laws** layer, ShipDesign now uses the user-confirmed `Owl-Listener/designer-skills` repository. Its UI Design and Visual Critique collections contain explicit perceptual-law, visual-hierarchy, and composition-review skills, so the previous temporary `vivaldi007/ux-psychology-skill` substitute has been removed from the bundle.

ShipDesign's own orchestration files are MIT licensed under the repository `LICENSE`.
