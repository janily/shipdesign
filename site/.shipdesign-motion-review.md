# Motion Review Ledger

Review evidence: production build rendered with Edge at desktop 1440px, tablet 768px, true mobile 390px CSS width, full-page 1440px capture, workflow anchor capture, and reduced-motion tablet capture.

## Findings before score

| ID | Scope | Severity | Evidence | User impact | Disposition |
|---|---|---|---|---|---|
| M-01 | content availability | Major | Initial reveal implementation hid below-the-fold sections in full-page and anchor captures until IntersectionObserver timing completed. | Review evidence could show blank sections and real users with delayed script execution could lose context. | Fixed by keeping sections fully visible at rest and animating transform only after client initialization. |
| M-02 | workflow comprehension | Major | Broad observer thresholds could mark more than one workflow row active during a fast scroll. | Multiple active stages weakened the meaning of the current handoff. | Fixed by selecting the single visible row nearest viewport center; previous rows remain complete. |
| M-03 | motion purpose | Minor | Reference-inspired motion could have spread into decorative parallax or animated body copy. | Extra motion would add cost without explaining orchestration. | Rejected. Only workflow state and section handoff reveal are animated. |
| M-04 | responsive motion | Minor | Sticky/pinned choreography is not suitable for small screens in this content density. | Complex pinning could reduce reading speed and touch usability. | Fixed by using normal flow and active color cues on mobile. |
| M-05 | reduced motion | Minor | Reduced-motion mode must preserve the complete sequence without transform dependency. | Users who disable motion still need the workflow and narrative order. | Fixed. Observer immediately marks content visible and CSS removes transforms/row highlight motion. |
| M-06 | originality | Minor | The page borrows scroll grammar from the reference video. | Overly recognizable choreography could make the page feel cloned. | Accepted. No source assets, copy, brand, timing, or signature sequence were copied. |

## Protocol checks

- Desktop, tablet, mobile, and full-page rhythm: checked.
- Scroll continuity and workflow active state: checked in the workflow anchor render and observer logic.

- ShipDesign identity: preserved through existing command-stage hero, acid signal, source names, workflow facts, orchestration copy, and install command.
